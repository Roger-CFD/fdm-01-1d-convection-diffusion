Objective: This project investigates the transport of temperature by means of convection and diffusion through one-dimensional domain using finite differencing methods.

Methodology: Discretization of 1st and 2nd order derivative for temperature using Taylor series expansion.

Implementation: Implement finite-central-differencing or finite-backward-differencing based on the péclet number.

Results: The cases differ in flow speed and mesh number. The results for each case are presented , followed by a comparison of the observed trends.
